Answer: [1, 2] — not [2].

Default argument values are evaluated once, when the function is defined — not on every call. Since lst=[] is only created a single time, the list from the first call (line 5) is still sitting there when the second call runs, so it grows instead of starting fresh.

Fix: use lst=None and create the list inside the function: if lst is None: lst = [].
