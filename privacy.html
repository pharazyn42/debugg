Privacy

Short version: your progress stays in your browser, and visits are counted without cookies or anything that identifies you.

What’s saved, and where

Your puzzle progress, XP, streak, company and sandbox drafts are saved in your own browser (local storage). They’re never sent anywhere. Clearing your browsing data deletes them, so use the backup link to keep a copy. The backup code contains only this progress.

This is a demo. When v0.1 comes out, all progress saved during the demo (puzzles, XP, streak and company) is deleted from your browser, and demo backup codes stop working. Sandbox drafts are kept.

Counting visits

Debugg uses GoatCounter to count visits. It sets no cookies, doesn’t track you across sites, and doesn’t store your IP address. As well as page views, it counts a few anonymous events so the puzzles can be improved:

  • a puzzle finished: its language and day, whether it was solved, and how many guesses and hints it took;
  • reaching a new level;
  • in Debugg Ltd: founding, pausing, resuming or closing a company, and hiring or promoting (just the role);
  • opening or using the backup, the feedback links, and running code in the sandbox (just the language).

What you type, like your answers and your sandbox code, is never sent.

Other services

  • The site is hosted on GitHub Pages, which, like any web host, sees your IP address when you load a page.
  • Running Python in the sandbox downloads Python (Pyodide) from the jsDelivr network the first time.
  • The fonts are served from this site, not Google Fonts.
  • The feedback and report links open a GitHub issue. GitHub issues are public, so don’t include anything personal.
